Risk Assessment

R1: rumps + PyQt6 Event Loop Conflict
Two different event loops (NSRunLoop vs Qt) cannot coexist in the same process.
Mitigation: QSystemTrayIcon first, rumps as fallback in separate process
R6: QThread Concurrency Issues
Multiple GitWorker threads accessing the same repository can cause race conditions.
Mitigation: Single worker queue pattern (one active GitWorker at a time)
R2: PyInstaller macOS Packaging
Hidden imports, data files, and code signing can cause build failures.
Mitigation: Smoke test on Day 1, CI build test throughout development
R5: GitPython Large Repo Performance
iter_commits on large repositories can be slow without limits.
Mitigation: Commit log limit, caching strategy via ConfigStore
R7: macOS Permission (.app filesystem access)
Sandboxed .app may not access external git repos or config files.
Mitigation: Early entitlements setup, sandbox testing in Phase 3
R3: AWS CodeCommit Authentication
HTTPS/SSH credential management could fail in .app context.
Mitigation: Use local git credentials as-is, support both SSH/HTTPS
